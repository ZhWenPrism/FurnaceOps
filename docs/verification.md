# 阶段原型验证记录

日期：2026 年 10 月 11 日。对象：本仓库 v0.1 本地原型。验证环境：macOS、Python 3.12、Codex 内置浏览器。

## 自动化检查

运行 `python3 -m unittest discover -s tests -v`，25 项全部通过。测试使用临时数据库和本地 HTTP 服务，不依赖企业系统。

- 数据来源标识、健康状态和构件数量一致。
- 构件搜索、类别查询、无匹配结果及不存在的构件处理正确。
- 有效零值保留为 `0.0`，缺测保留为 `null`，过期值与未来时间分别标识。
- 历史序列保持 24 个时间点和缺测位置；全缺测序列不补造测值。
- 按构件和阶段筛选记录，分页与空结果符合预期。
- CSV 使用 UTF-8 BOM，导出全部匹配记录并保留数据来源；分页不会截断导出，公式前缀作转义处理。
- 无效参数、注入式参数及越界路径受到限制；写入方法返回 405。
- 静态文件、安全响应头及样例初始化幂等性检查通过。

JavaScript 语法检查通过。上述测试不等同于生产安全审计、负载测试或现场验收。
